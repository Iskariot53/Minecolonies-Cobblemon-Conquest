Changes


- Added compat tags and silk overrides for ambiguity ore.
- Added new colonist stat modifiers giving colonists a higher base stat total overall, as well as "on the job training" training buffs.
- Added the ability to summon the Trainer Association Rep to a trainer spawner,  by R-clicking a trainer card on the spawner.
- Fixed Amaramber and Aethersent bee flowering.
- Fixed Rendering conflict with carved pumpkins.
- Fixed poser conflicts causing certain Cobblemon to fail to render properly under certain circumstances, IE: Bidoof spawning as female.
- Added the ability to set day/night as well as weather using cobblemon interactions on a configurable per-player cooldown. Config settings can be found in cce-common.toml
	- If a cobblemon knows Sunny Day it can set the time to day and set weather to clear.
	- If a cobblemon knows Rain Dance it can set the weather to rain.
	- If a cobblemon knows Moonlight it can set the time to night.
	- If a cobblemon knows Thunder or Hurricane it can set weather to thunderstorm.
